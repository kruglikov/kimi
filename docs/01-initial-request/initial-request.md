**#1 Scope of the Initial Analysis**  
As part of an initial analysis, the existing PHP system [kimiportal.at](http://kimiportal.at "http://kimiportal.at") (PHP version 8.0.30) with an SQL database (version 10.5.21-MariaDB) shall be examined regarding the necessary code adjustments for operation on a new, current PHP version. The objective is to verify the feasibility of migrating to a PHP version that is current at the time of implementation and is expected to be supported for at least two more years—PHP 8.4+.  
`**#2 Objectives of the Analysis**  
The analysis is intended to provide the following results in particular:  
Identification of necessary code migrations for the PHP version upgrade.  
Rough estimation of the migration effort.  
Assessment of critical code sections and technical risks.  
Initial evaluation of which components involve a higher need for testing or adjustment.  
The focus shall be on the migration to a current PHP version as well as the relevant security requirements with regard to the EU GDPR (DSGVO).  `
**#3 Delimitation (Out of Scope)**  
The following are not subject to this analysis:  
Code optimizations.  
Refactoring.  
Functional enhancements.  
Changes to the database structure.  
Content-related or functional further developments.  
The analysis serves exclusively for the technical assessment of the required adjustments regarding PHP compatibility and relevant security requirements.  
# 4 Basis of the Analysis  
The following documents and information will be provided for the analysis:  
- General documentation of the system, specifically regarding:  
- Permissions.  
- Session handling.  
- Dialogs.  
- Search masks and detail changes.  
- Telephony integration.  
- JavaScripts for input validation.  
- Batch components.  
- General structural description.  
- The PHP source code of the system.  
- PHP info files.  
- Database structure.  
#5 Testing and Verification  
Testing of the migrated components will be carried out at or by KIMI. If required for the analysis or verification, a small test database can be provided or created.  
#6 Form of Results  
The expected output of the initial analysis is a high-level technical assessment that specifically:  
Identifies the affected system areas.  
Summarizes the necessary adjustments.  
Highlights critical points.  
Roughly estimates the effort in an appropriate format.
